# Low-T-depth-quantum-circuit-of-ZUC-128

## 1. `ZUC_classical/`

**Description**:  
The code corresponds to the method described in **Section 3.2**, where a SAT-based approach is used to search for efficient circuit representations of the ZUC-128 S-box.

## 2. `CNOT_Optimization_MILP/`

**Description**:  
The code corresponds to the optimization framework described in **Section 3.3**, where a MILP-based method is used to optimize CNOT-based quantum circuits. A sample file is included for demonstration.

## 3. `ZUC_result/`

**Description**:  
This folder contains the final quantum implementations of the ZUC-128 S-boxes **S₀** and **S₀⁻¹**.
